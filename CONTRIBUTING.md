# Contributing

First of all, thank you for your interest in contributing to KeyClickOverlay!

Whether you're reporting a bug, suggesting a new feature, improving the documentation, or contributing code, your help is greatly appreciated.

## Reporting Bugs

Before creating a bug report, please check whether the issue has already been reported.

When reporting a bug, please include as much information as possible, such as:

- The version of KeyClickOverlay.
- Your Windows version.
- Steps to reproduce the issue.
- The expected behavior.
- The actual behavior.
- Screenshots or screen recordings, if applicable.

## Suggesting Features

Feature suggestions are always welcome.

When proposing a new feature, please describe:

- The problem you're trying to solve.
- Your proposed solution.
- Any alternative solutions you've considered.

Keep in mind that not every feature request can be implemented, but all suggestions are appreciated.

## Pull Requests

Before opening a pull request, please ensure that:

- Your changes are focused on a single improvement or fix.
- Existing functionality continues to work as expected.
- New functionality has been tested.
- Documentation is updated where necessary.

Please write clear commit messages and provide a concise description of your changes.

## Code Style

There is currently no formal coding standard for this project.

Please follow the existing coding style and conventions used throughout the codebase whenever possible.

## Project Maintenance

KeyClickOverlay is currently maintained by a single developer.

Contributions are always welcome, and if the project continues to grow, I would be happy to collaborate with additional maintainers.

If you have been making high-quality contributions over time and are interested in helping maintain the project, feel free to get in touch.

## Questions

If you're unsure about a proposed change, feel free to open a discussion or issue before starting work.

## Thank You

Every contribution, no matter how small, helps improve KeyClickOverlay.

Thank you for taking the time to contribute!
